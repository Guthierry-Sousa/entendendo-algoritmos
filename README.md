# Entendendo Algoritmos

Repositório destinado aos meus estudos e implementações relacionados ao livro **Entendendo Algoritmos**, de Aditya Bhargava.

## Conteúdo

Este repositório contém:

* Implementações dos algoritmos apresentados no livro.
* Exercícios e problemas propostos durante os estudos.
* Testes e experimentações com diferentes algoritmos e estruturas.
* Anotações e exemplos práticos relacionados aos conceitos abordados.

## Conteúdos Abordados no Livro
* **Capítulo 1**: Introdução a algoritmos (definição, pesquisa binária e notação Big O)
* **Capítulo 2**: Ordenação por seleção (arrays, listas encadeadas e selection sort)
* **Capítulo 3**: Recursão (definição, características e pilha)
* **Capítulo 4**: Quicksort (dividir para conquistar, quicksort e revisão notação Big O)
* **Capítulo 5**: Tabela Hash (funções hash, utilização, colisões e desempenho)
* **Capítulo 6**: Pesquisa em Largura (grafos, implementação de grafos e BFS)
* **Capítulo 7**: Algoritmo de Dijkstra (implementação, utilização) 
* **Capítulo 8**: Algoritmos Gulosos
